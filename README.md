# A* Search Route Optimisation

This project implements the A* Search algorithm to determine the
minimum-cost route from Sunway University to five residential locations.

The path cost combines:

- 60% normalised carbon emission
- 40% normalised travel expense

## Optimal Route

SunU → Vidhipriya → Wen Li → Hui San → Keertana → Qi Yung

Total path cost: 1.11854

## Repository Contents

- `colab/` — Google Colab notebook containing the A* implementation
- `vscode/` — Python scripts used to generate the route video and diagrams
- `outputs/` — Generated graph and flowchart images
- `requirements.txt` — Required Python libraries
